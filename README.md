# CEBONK Swing v1.10 feed

Public data branch for the EA weekly direction lock and strict weekly/daily/session alignment.

`forecast.json` is feed schema 2.1.0, model CEBONK_SWING_ASTRO_WEEKLY_LOCK_7D_V1, M5 MUSANG_EL2_IB_CB1_RETEST.

The feed contains astronomical forecasts, not broker orders or verified trading performance. No credentials or account information. SHA-256 integrity, UTC publication/expiry, seven-day strength evidence. Publication validity is at most 30 hours. The EA waits after expiry.
