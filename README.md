# CEBONK Killzone Astrology WebRequest feed

forecast.json contains only the five independent Astrology Killzone session forecasts. It is generated from the unmodified source snapshot recorded in the payload. No broker data, account information, tokens, ICT, Fibonacci, or trading orders are included.

The source repository PR adds the daily publisher; scheduling starts after that workflow is merged into main. This branch is the stable public data endpoint.
